# Agent Guidelines

## Stack & Tooling
- **Language**: Python 3.11+
- **Testing**: `pytest`
- **Test Command**: `pytest`

## Naming Conventions
- Standard Python `snake_case` for module names, functions, methods, and variables.
- `PascalCase` for class names.
- Descriptive module and file names.

## Critical Rules
- **Do not change the data model without updating SPEC.md first.**
